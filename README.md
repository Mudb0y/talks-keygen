# talks-keygen

Keygen for Nuance Talks and Zooms

## What exactly is this?

This is a keygen for Nuance Talks and Zooms, legacy accessibility software for S60. Unfortunately there is no way to buy or in any capacity register this software anymore as the activation servers are long gone so if you install it stock you're left with a really shitty 10 minute demo.

## Usage

You need Python to use this. Run the script in the repository, follow the pprompts, profit!
